SiteVitals

A 5-minute security report card for your website and repo.

Paste a URL, get a scored report card with prioritized, copy-paste fixes. Point it at a local repo, get a separate repo score: leaked secrets, vulnerable dependencies, and injection-pattern risks — no shell-outs, no live verification of secrets, and only package names + versions ever leave your machine (for the OSV lookup).

What it checks

URL mode: HTTPS redirect, security headers (HSTS, CSP, framing, nosniff, referrer-policy, Permissions-Policy, isolation headers), cookie flags (Secure + HttpOnly + SameSite), TLS certificate + version + expiry window, DNS (SPF, DMARC, CAA), /.well-known/security.txt.

Repo mode (sitevitals repo <path>): secrets (vendored MIT Gitleaks rule patterns, redacted reporting), vulnerable dependencies via OSV (npm, PyPI, Go), injection patterns, Dockerfile hygiene, license audit, CI config, and a CycloneDX SBOM export (--sbom).

Output: a human report card (self-contained HTML) plus --json for agents and CI. All checks are passive reads — no scans, no payloads.

Run it

git clone https://github.com/ApoorvRusia/sitevitals.git
cd sitevitals
npm install && npm run build
node dist/cli.js https://example.com        # URL report card
node dist/cli.js repo /path/to/your/repo    # repo score

Limits

SiteVitals is a hygiene check, not a penetration test. It will not find application vulnerabilities. It makes sure the front door is locked, the windows are latched, and the alarm is on.

Roadmap

Git-history scanning, GitHub-URL input, web UI.
